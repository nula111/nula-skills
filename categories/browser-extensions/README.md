# 🧩 Browser Extensions

浏览器扩展工具集合

## 📋 Contents

### resume-filler-extension
简历自动填充助手 - 帮助用户在招聘网站自动填充简历信息

**功能特性：**
- ✅ 支持多招聘网站简历自动填充
- ✅ PDF/Word 简历解析导入
- ✅ 用户反馈纠错学习系统
- ✅ 半自动字段识别
- ✅ 支持 BOSS直聘、智联、51job、猎聘、拉勾等

**安装方式：**
1. 克隆本仓库
2. 打开 Edge/Chrome 扩展管理页面
3. 开启开发者模式
4. 加载 `resume-filler-extension` 文件夹

详细使用说明请查看 [SOP.md](./SOP.md)
